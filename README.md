# Festival de Música 2026 - Landing Page Demo

Una página de aterrizaje (landing page) moderna y responsiva desarrollada para promocionar un festival de música ficticio. Este proyecto demuestra el uso de maquetación semántica en HTML5 y estilos avanzados con CSS3 puro, incluyendo el popular efecto de diseño *Glassmorphism*.

## 🚀 Características Principales

- **Efecto Glassmorphism:** Interfaz elegante con fondos oscuros semitransparentes y desenfoque (`backdrop-filter`) que permite apreciar la imagen de fondo manteniendo una alta legibilidad.
- **Navegación Sticky:** Menú superior que se mantiene fijo y visible mientras el usuario hace scroll, mejorando la experiencia de navegación.
- **Diseño 100% Responsivo:** Adaptación perfecta a dispositivos móviles, tablets y escritorio. Incluye técnica de relación de aspecto (16:9) para elementos multimedia embebidos (*iframes* de YouTube y Google Maps).
- **Tipografía Moderna:** Integración con Google Fonts utilizando **Bebas Neue** para titulares impactantes estilo póster de concierto, y **Poppins** para una lectura limpia y fluida.
- **Formulario UI/UX:** Formulario de registro con etiquetas semánticas, validación básica nativa y un diseño limpio basado en Flexbox.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del documento.
- **CSS3:** 
  - Uso de variables globales.
  - Flexbox para alineación y distribución de elementos.
  - Efectos visuales avanzados (gradientes lineales, opacidad, transiciones suaves).

## 📂 Estructura del Proyecto

```text
/
├── index.html          # Estructura y contenido principal de la web
├── styles.css          # Estilos globales y reglas de diseño responsivo
└── assets/
    └── festival.webp   # Imagen principal utilizada como fondo fijo
```

## 💻 Instrucciones de Uso

1. Clona este repositorio o descarga los archivos fuente.
2. Crea una carpeta llamada `assets` en la raíz del proyecto y añade una imagen de fondo nombrada `festival.webp` (o modifica la ruta en el archivo `styles.css`).
3. Abre el archivo `index.html` directamente en tu navegador web preferido. No requiere servidor local ni dependencias de Node.js.
